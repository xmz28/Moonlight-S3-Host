# Moonlight S3 Host

Windows 配套软件，用 JPEG 将选定显示器发送到 ESP32-S3 RGB 触屏，并接收触摸控制。
本仓库为 [Moonlight-S3-Host](https://github.com/xmz28/Moonlight-S3-Host)，配套固件见 [Moonlight-S3](https://github.com/xmz28/Moonlight-S3)。两个项目可分别下载、构建，源码目录无需放在固定位置。

## 启动

公开包解压到可写目录后运行 `MoonlightS3Host.exe`（保留旁边 `_internal` 整个目录）。本机构建的公开包在 `dist-release/MoonlightS3Host-windows.zip`；原开发版仍在 `dist/MoonlightS3Host/`。
本机参数、电脑身份及配对凭据统一保存到 `%LOCALAPPDATA%\MoonlightS3Host\settings.json`，不纳入公开包。首次使用新版自动迁移程序旁旧配置并保留原文件，之后更换解压目录仍保持同一电脑身份。旧固定密钥已停用；上一版四位码配对会迁移保留。
也可运行源码 `python main.py` 或双击 `start.cmd`。

1. 电脑软件保持打开；两端接入同一局域网。S3的Wi-Fi可在屏上设置，也可使用USB配网。
2. 在 S3 首页扫描并点击电脑。已配对直接串流；首次需要配对时，电脑自动弹出PIN窗口。
3. 在电脑输入 S3 显示的四位 PIN，验证后自动开始；下次不再输入。
4. 底栏 LEFT / RIGHT / SCROLL 操作电脑，KEYBOARD 打开 S3 本地文字输入，BACK 返回电脑列表。底部 BACK 右侧 MENU 始终可用，可暂停、继续、重连或断开，断开保留电脑应用。
5. 查看或删除授权统一在“已配对设备”。任一端删除后，下次串流自动进入首次配对。

不再提供手动配对按钮、配对开关、长密钥或电脑端开始按钮。S3 发起连接后自动选中正确接收端，显示等待响应、验证、准备桌面和首帧等阶段。PC 取消 PIN 会反馈到 S3；S3 返回会取消旧请求，阻止迟到连接。

显示器、画质、FPS、底栏、控制权限及直接触摸/单指触摸板在 S3 的每台电脑设置中记忆。仅观看禁止鼠标、快捷键和文字注入，仍可通过本地 MENU 退出。单指轻点左键、长按右键；直接触摸移动拖动，触摸板通过快速第二次按住拖动。滚轮使用 SCROLL 单指滑动，无需双指。本地文字键盘当前支持英文、数字与符号，不含中文输入法。

关闭电脑设置窗口会收起到系统托盘并继续待命；托盘可重新打开或退出。可选“开机后台运行”，默认不启用。高级区域只保留网络诊断、USB 配网和兼容选项。连接阶段和错误写入配置同目录的轮换 `diagnostics.log`，不记录 PIN 或长期凭据。
开始前不会抓取桌面；程序不录屏、不上传第三方、不自动设置防火墙、不监听公网端口。
主机帧内绘制可见鼠标箭头；它是位置标记，不保证与 Windows 每种自定义光标形状一致。

S3 仅使用路由器 STA 模式，不开热点，连接失败也不退回热点；断线自动重连。
电脑可用5GHz Wi-Fi或有线，只需与S3所在网络互通。配置工具不保存或输出Wi-Fi密码。
如果不方便USB配置，可在固件的本地 `config_secrets.h` 中设置路由器SSID/密码后编译。
UDP47990用于局域网发现，TCP47989用于串流。发现失败时可直接填写屏幕上的IP，
或设备的 `moonlight-s3-xxxxxx.local` 主机名（需要电脑支持mDNS）。
访客Wi-Fi客户端隔离、跨子网广播限制或防火墙可能阻止搜索；程序不会自动修改防火墙。
主机支持 Windows 多显示器、负坐标和 DPI 感知；比例保留，黑边不触发点击。
运行期间配置锁定，要修改参数先停止。

## 性能含义

默认 400×240 / 25FPS / quality60，S3 放大显示到800×480。
电脑优先使用 DXGI 桌面复制；先缩小 BGRA 像素，再在小图上转换颜色、画工具栏和编码 JPEG。
DXGI 不可用时依次回退到 GDI 缩放抓屏和 MSS；界面会显示实际使用的抓屏方式。
多显示器通过完整桌面坐标匹配，不能匹配时回退，不猜测显示器编号。
800×480 档更清晰，但 S3 软件 JPEG 解码速度可能达不到20FPS。
面板默认12MHz扫描约25.36Hz，主机目标30FPS不会提高这个上限。
实际性能必须烧录后测量；GUI显示接收端确认的帧率、解码耗时、显示处理耗时、帧确认时延。
默认开启“流畅优先”，最多三帧在途以填满处理管线；关闭后最多两帧，减少排队。
两种模式都只在有空位时捕获新屏幕，不持续积累截图队列；差网络仍受 TCP 重传影响。

这是独立 JPEG 协议，不是 Moonlight/Sunshine 客户端，没有音频或公网中继。
需访问云主机时，应让 S3 与 Windows 主机通过本地网络或自备 VPN 可路由互通。
协议未加密，仅供可信网络。Windows SendInput 受 UIPI 限制：普通权限不能操作高权限窗口/UAC 安全桌面。
快捷键/文字输入作用于电脑当前焦点窗口，受 Windows 权限限制。

配套新版 S3 支持本地性能浮窗，可在 MENU 或电脑设置页开关，默认关闭。显示实际显示 FPS、解码/显示处理耗时、帧确认 ACK、JPEG 接收 Mbps 和 Wi-Fi 信号。ACK仍是帧处理确认时间，不是ping；网络速率表示本次串流流量，不是链路测速。电脑只在开启时每秒发送16字节统计消息，并在关闭时发送一次状态更新。底栏六个按键已统一宽度，两端需同步更新以匹配新的触摸分界。

MENU 暂停断连修复版还需配套支持 PAK3 暂停确认的 S3 固件：先收完在途画面，再显示本地菜单。电脑控制包与帧共用部分写入重试，避免100ms收包超时误中断菜单心跳；真实断线检测仍为3秒。

## 构建和测试

Windows 开发环境使用 Python 3.12，依赖精确版本在 `requirements.txt`。本机继续复用现有 Python；其他开发者可按自己的环境运行 `python -m pip install -r requirements.txt`。

```powershell
python -m unittest discover -s tests -v
python main.py --gui-smoke
python main.py --capture-smoke
.\build.ps1
```

先运行上述测试命令，再用 `build.ps1` 通过 PyInstaller 生成 Windows onedir 软件。脚本输出到独立 `dist-release/`，保留原 `dist/` 及源码目录的本机配置。公开 ZIP 不包含 `settings.json`，并附 `SOURCE.txt` 和 `SHA256SUMS.txt`；工作区有修改时，源码信息会明确标为待审核构建，正式版本应从干净 tag 构建。详见 [发布说明](RELEASING.md)。
打包软件自带 Python runtime，使用者不需要安装 Python；这不是另建开发虚拟环境。
`--gui-smoke` 只创建界面后退出，不连接 S3，不捕获或控制桌面。
`--capture-smoke` 实际验证 DXGI 抓屏及 JPEG 编码，不保存图像、不连接 S3、不注入输入。
显式实机基准：`python tools/benchmark_stream.py --serial COM17 --output build/benchmark.json`。
该命令使用真实桌面、quality60、目标25FPS，默认每档25秒，并关闭触摸控制。先从托盘退出正常软件，每一档按控制台提示在 S3 点电脑授权本次测试；工具仍遵守 v3 请求门控。输出不包含配对码。

测试通过 loopback 模拟 S3，与虚拟鼠标验证协议和安全释放，不会移动真实鼠标。
发现测试用本机UDP模拟回复；配网测试使用虚拟串口对象，不打开实际串口。
已完成实际投屏、基本触摸回传和 Windows 控制，用户确认画面/操作正常。

## 自动配对与设备管理

S3列表通过电脑公告检查双端配对状态，按完整身份区分同名设备。首次从S3点选电脑，电脑自动弹窗输入PIN；配对成功自动串流。已有配对直接启动；BACK回到列表。S3保存最多四台电脑，电脑可保存多个S3；管理页删除某一台不影响其他授权。

电脑使用稳定computer_id，已有四位码凭据会迁移保留。授权保存在忽略的settings.json；源码与开发版打包目录各有本机配置，公开包不携带这些配置。此前37项软件测试及打包GUI smoke通过，用户已确认电脑列表、直接串流、返回、删除后首次状态及自动弹窗/串流全部正常。设备协议和边界见固件docs/PAIRING.md。


## 自动验证和防重放

首次PIN授权后，双方保存会话派生的长期密钥。每次连接由S3生成新的32-byte随机挑战，电脑用HMAC-SHA256返回证明，S3也向电脑返回另一方向的证明；长期密钥不直接发送。旧认证报文不能直接拿到新连接重放。原理、实机历史记录和完整边界见固件docs/PAIRING.md。

此处防护针对认证握手；当前JPEG/触控仍未加密和逐报文认证，不能据此防实时中间人转发或业务数据篡改/重放。本机settings.json保存的凭据未加密，不纳入Git。

## S3重启与IP自动更新

授权按固定设备ID保存，IP只是当前连接地址。S3重启、DHCP换地址后，电脑软件在空闲时每约4秒重新发现设备；验证原配对凭据后自动更新地址及本地记录，不需要手填新IP或重新配对。手填地址与历史地址只作备用，不会覆盖新发现的端点。

从电脑点击开始时，也会先按完整设备ID重新定位并验证接收端，再建立串流。查找失败保留原配对，等S3联网后重试；只有任意一端删除授权、实际凭据丢失或更换电脑身份才需要再次PIN配对。

同一Windows登录会话只运行一个交互实例，再次打开会切回现有窗口，避免多个窗口争抢连接或覆盖设置。配置采用临时文件加原子替换，写入失败保留旧配置；损坏配置不会被静默清空并生成新身份。源码GUI smoke不再改写本机设置。
